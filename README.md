

# 🧾 Resume Generator

A modern, responsive Resume/CV Generator built using HTML, CSS, and JavaScript only.
Create a clean, professional resume and export it as a PDF with a single click — no backend, no frameworks, no hassle.

# ✨ Features

🖊️ Easy Resume Creation – Fill in your details and instantly see the preview  
📄 One-Click PDF Export – Use the Print button to download or print your resume  
📱 Fully Responsive – Works smoothly on desktop, laptop, and tablet screens  
🎨 Modern & Clean Design – Simple layout suitable for professional use  
⚡ Fast & Lightweight – Pure HTML, CSS, and JavaScript (no dependencies)

## How It Works:
1.Enter your personal, academic, and professional details  
2.Instantly preview your resume in a clean layout  
3.Click the Print button  
4.Choose Save as PDF or print directly
